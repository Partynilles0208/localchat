# Clean Slate — Monochrom Messenger

Ein kompromisslos minimalistisches, extrem reduziertes Chat-Interface im **Schweizer Monochrom-Stil** mit **vertrauenswürdiger Sicherheits-Anmeldung**.

Keine Sci-Fi-Elemente, kein Cyberpunk-Kitsch, keine klobigen Vorlagen-Elemente — sondern **reine Ästhetik, haardünne Kanten, gestochen scharfe Typografie und null visuelle Ablenkung**.

---

## 🔒 Vertrauenswürdige Anmeldung (Trusted Auth)

- **Seriöses Sicherheits-Interface:** Diskreter Sicherheits-Badge (*„Ende-zu-Ende verschlüsselt“*), saubere Eingabefelder für Benutzername und Passwort mit Passwort-Sichtbarkeitsumschalter (Auge-Icon).
- **Flexibel:** Umschalten zwischen *„Anmelden“* und *„Konto erstellen“*.
- **Datensparsam & Sicher:** Alle Schlüssel und Profildaten verbleiben lokal auf dem Gerät.
- **Sitzungsverwaltung:** Option *„Angemeldet bleiben“* (persistiert im Browser-Speicher) sowie ein direkter **Abmelde-Button** unten links in der Seitenleiste.

---

## 💎 Design-Prinzipien

- **Reines Monochrom:** Tiefes, mattes Obsidian-Schwarz (`#09090b`), reines Weiß (`#ffffff`) und fein abgestufte Grauwerte (`#a1a1aa`, `#27272a`).
- **Haardünne 1px-Kanten:** Präzise, unaufdringliche Begrenzungen ohne übertriebene Schlagschatten.
- **Null Ablenkung:** Keine Hologramme, keine animierten Intros, keine übertriebenen Badges — 100% Fokus auf deine Unterhaltungen.
- **Sauberer Start:** Keine fest einprogrammierten Beispielkontakte. Lege deine Kontakte einfach über `+ Neuer Chat` an.
- **Dark / Light Modus:** Per Klick auf das Mond/Sonne-Symbol kannst du jederzeit zwischen dem dunklen und hellen Monochrom-Modus wechseln.
